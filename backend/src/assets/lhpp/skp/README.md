# Lampiran SKP LHPP

Generator melampirkan dua halaman contoh SKP untuk bidang berikut: PAA, PUBT,
PTP, IPP, LIS, dan IPK. `company-appointment.jpg` berisi keputusan penunjukan
perusahaan PJK3 beserta penanggung jawab yang tercantum di dalam keputusan.
`expert-appointment.jpg` berisi keputusan penunjukan Ahli K3 bidang terkait.

Untuk memperbarui lampiran, ganti berkas dengan nama yang sama di folder kode
bidangnya. Untuk menambah halaman atau bidang, tambahkan nama berkas pada
`manifest.json` dan letakkan berkasnya di folder bidang yang sesuai.

Belum tersedia contoh LHPP bidang Elevator dan Eskalator (LE), sehingga belum
ada lampiran SKP LE yang dipasang. Dokumen contoh berisi nama pemegang SKP
sebagaimana tercantum pada berkas rujukan.
