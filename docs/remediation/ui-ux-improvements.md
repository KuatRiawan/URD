# Perbaikan UI/UX

- Aksi auto-fill yang berisiko telah dihapus dari checklist.
- Work queue diarahkan untuk menampilkan pekerjaan yang membutuhkan tindakan.
- Status sinkronisasi offline kini memberi umpan balik keberhasilan dan kegagalan.
- Distribusi dokumen dan renewal mendapat guard agar retry tidak membuat data ganda.
- Portal tidak menampilkan kembali token rahasia setelah pembuatan.

Validasi visual manual pada ukuran mobile dan desktop tetap diperlukan untuk memastikan tabel, modal, dan CTA tidak menyembunyikan informasi penting. Perubahan berikutnya harus mempertahankan Bahasa Indonesia, logo resmi, satu library ikon, dan tidak menambah tombol tanpa alur nyata.
