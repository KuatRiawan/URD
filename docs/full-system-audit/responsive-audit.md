# Audit responsif

| Viewport | Area | Hasil |
|---:|---|---|
| 375 px | Login mobile, light/dark | Form dan logo tampak; screenshot tidak menunjukkan overflow horizontal. |
| 390 px | Login | Kontrol form ada di accessibility tree. |
| 430 px | Login | Kontrol form ada di accessibility tree. |
| 768 px | Login/tablet | Kontrol form ada di accessibility tree. |
| 1280 px | Login/laptop | Kontrol form ada di accessibility tree. |
| 1440 px | Login desktop | Panel identitas dan form tampil berdampingan. |

Hanya halaman login yang diuji. Inspector mobile, sidebar, tabel, modal, kalender, upload, signature canvas dan PDF belum dinyatakan responsif. Viewport browser sementara dikembalikan setelah pemeriksaan.
