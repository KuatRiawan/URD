# Admin Sistem: perjalanan pengguna

Login normal sebagai Admin Sistem, buka Manajemen Pengguna, periksa filter role, dan buat akun Inspector uji dengan alamat perusahaan pada database simulasi. Form menampilkan kolom NIP setelah role Inspector dipilih. Pembuatan sukses dan notifikasi UI mengonfirmasi. SQL membaca akun aktif ber-role `INSPECTOR`.

Filter Marketing setelah perbaikan memetakan alias historis agar akun lama tetap dapat ditemukan. Pembuatan akun tidak mengubah akun yang sudah ada. Edit status, reset kata sandi, master data dan template tidak diuji.
