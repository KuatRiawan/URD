# Marketing: temuan

Tidak ada kegagalan alur PO yang terkonfirmasi pada cakupan yang dijalankan. Ada keterbatasan uji tanggal: nilai input kalender berubah pada UI saat diisi otomatis, tetapi nilai review dan record tetap tanggal default; belum direproduksi dengan interaksi kalender manual, maka statusnya **belum terkonfirmasi**, bukan bug terverifikasi. Lampiran PO belum diuji.
