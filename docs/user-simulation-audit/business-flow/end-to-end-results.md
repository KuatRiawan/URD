# Alur bisnis ujung ke ujung

Marketing → penugasan → penerimaan Inspector → mulai inspeksi berjalan sampai draf pemeriksaan per unit. Verifikasi API dan DB membuktikan PO, tiga objek, satu assignment dan dua draft inspection. Tidak ada hasil teknis, tanda tangan, atau dokumen resmi yang dibuat.

Alur dihentikan sebelum submit inspeksi karena hasil perlu berasal dari pemeriksaan fisik yang nyata. Maka generasi/finalisasi LHPP, BAP dan pencatatan distribusi tidak dapat diklaim berhasil melalui browser. Suite backend memiliki skenario integrasi multi-unit LHPP/BAP/distribusi otomatis, tetapi itu bukti test API, bukan pengganti penyelesaian workflow lapangan di UI. Tidak ada dokumen dikirim ke klien/Disnaker.
