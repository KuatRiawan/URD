# Keputusan Owner yang Masih Pending

1. Pilih jadwal reminder internal: H90/H60/H30/H14/H0.
2. Pilih jadwal reminder klien: H7/H14/H30 atau model lain.
3. Tetapkan apakah reminder internal dan klien dijalankan sebagai scheduler terpisah.
4. Tetapkan mapping akun produksi legacy Marketing/Admin Kantor.
5. Setujui lifecycle cancel, correction, reissue, nomor revisi, dan approver dokumen.
6. Tetapkan retention, legal hold, backup, restore test, dan owner kebijakan.
7. Tetapkan apakah ada batas renewal aktif per unit atau hanya pencegahan duplikasi aktif berbasis unit/Suket.
8. Tetapkan status formal kompetensi seperti pembekuan atau pencabutan sertifikat.

Tidak ada perubahan permission produksi, migrasi data produksi, atau kebijakan baru untuk daftar di atas.
